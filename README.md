# Currency-converter

A simple and responsive currency converter built using HTML, CSS, and JavaScript. It uses the Exchange API to fetch current exchange rates and convert currencies.

## 🚀 Features

- Convert between different currencies
- Fetches exchange rates using an API
- Currency dropdowns with country flags
- Automatically updates currency flags
- User-friendly interface
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Exchange API
